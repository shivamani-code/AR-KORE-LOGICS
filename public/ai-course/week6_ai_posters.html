// WHAT IS A VARIABLE?
📦 Variables — Named Storage Boxes in Computer Memory
A variable is a named storage location in the computer's memory. Think of it as a labelled box: you put a value inside (assign), label it with a name, and use that label anytime you need the value back. In Python you create a variable simply by assigning it: name = "Arjun". No declaration, no type needed upfront — Python figures out the type automatically! This is called "dynamic typing" and is one reason Python is so beginner-friendly.
// THE 4 BASIC DATA TYPES IN PYTHON
🔢
int
age = 14
Whole numbers — no decimals. Can be positive, negative, or zero. Used for counting, indexing, and any calculation that does not need a decimal point. Examples: score, year, number of days.
🌡️
float
height = 1.58
Numbers WITH decimal points. Used for measurements, scientific values, percentages, and money calculations. Examples: temperature (36.5), PI (3.14159), bank balance (₹1250.75).
📝
str
name = "Arjun"
Text — always inside quotes (single ' or double " both work). Can contain letters, numbers, spaces, and symbols. "14" is a STRING, not a number — you cannot add it to an integer without converting first!
🔘
bool
is_student = True
Only two possible values: True or False (CAPITAL T and F in Python — it matters!). Used in conditions and logic. The foundation of every decision your program makes. Every if-statement relies on a boolean!
// VALID vs INVALID VARIABLE NAMES
✅ Valid Names
name
student_name
score2024
_private_var
Rules: start with a letter or _, no spaces, no special characters except _, case-sensitive (Name ≠ name)
❌ Invalid Names
2name (starts with number)
my name (has a space!)
for (reserved keyword)
student-name (hyphen!)
Reserved: if, else, for, while, def, class, import, True, False, None, and, or, not...

🔑 The Modulo % Operator — Super Useful!
7 % 3 = 1 because 7 ÷ 3 = 2 remainder 1. The % gives you only the REMAINDER.

Most common use: checking if a number is even or odd:
if number % 2 == 0: print("Even")
Works because even numbers always have remainder 0 when divided by 2. This exact check appears inside almost every AI data processing loop!
📝 f-strings — The Modern Way to Format Output
Put an f before the quote, then use {variable} inside:
name = "Arjun"
age = 14
print(f"Hi! I am {name}, age {age}")
Output: Hi! I am Arjun, age 14
Much cleaner than using multiple commas in print()!

// print() — ALL THE WAYS TO USE IT
🖨️
Basic print()
print("Hello")
Displays text on screen and moves to the next line automatically. The most used function in all of Python. Every output in every program goes through print()!
➕
Multiple Items
print("Name:", name, "Age:", age)
Separate items with commas. Python automatically adds a space between them. You can mix strings and variables freely in one print() call.
✨
f-strings (Best!)
print(f"Hi {name}, you are {age}")
The cleanest, most modern way. Put f before the quote. Use {variable} to embed any variable directly inside the string. Used by all professional Python developers!
🔧
sep= and end=
print("a","b","c", sep="-")
sep= changes the separator between items (default: space). end= changes what comes after print (default: new line). Advanced but very handy!
// input() — THE CRITICAL RULES YOU MUST KNOW
⚠️ The 3 Golden Rules of input()
🚨
Rule 1 — input() ALWAYS returns a STRING, no matter what the user types!
If user types 14, Python stores the TEXT "14" — NOT the number 14. You CANNOT do maths on it without converting first. This is the #1 source of errors for all beginners worldwide!
🔄
Rule 2 — Convert IMMEDIATELY using int() or float():
age = int(input("Enter your age: ")) — Now age stores the INTEGER 14. You can add, subtract, compare it. Always wrap input() with the right conversion function when you need a number!
📋
Rule 3 — Know your 3 type conversion functions:
int("42") → 42  |  float("3.14") → 3.14  |  str(100) → "100". These convert between types. Use them whenever data changes form!

// THE 5 MOST COMMON PYTHON ERRORS — AND HOW TO FIX THEM
  • SyntaxError

    You wrote something Python cannot understand grammatically

    Causes: missing colon after if/for/while/def, unclosed quotes or brackets, wrong indentation. Fix: read the error line number carefully — Python tells you exactly WHERE the problem is. Look at the line before the error line too!

  • NameError

    You used a variable that doesn't exist yet

    Causes: typo in variable name (stuName vs studentName), using a variable before assigning it, forgetting to create the variable. Python is case-sensitive — Name and name are DIFFERENT variables!

  • TypeError

    You tried to do an operation on the wrong data type

    Most common: age + 5 where age is a string from input(). Fix: convert first with int(age) + 5. Also occurs when calling a function with wrong argument types.

  • IndentationError

    Your indentation is inconsistent or missing

    Python uses indentation (4 spaces or 1 Tab) to define code blocks — unlike most languages that use {}. Mixing spaces and tabs causes this error. Fix: use ONLY spaces (4 per level) throughout your file. VS Code auto-fixes this if you use the Tab key!

  • ValueError

    You passed the right type but an impossible value

    Causes: int("hello") — you cannot convert text to integer. int("3.14") — use float() for decimals. This often happens when users type letters in an input() that expects a number. Always handle bad inputs gracefully!
